# 角色卡提取工具 · SillyTavern 扩展

把**小说正文**转成可直接在酒馆使用的**角色卡 / 世界书 / user 人设 / 开场白 / 文风**，并直接写入酒馆。

- 使用**酒馆当前 API 连接**，无需另填 API Key / BaseUrl
- 角色卡**先预览确认**，再写入酒馆
- **时间线（章节轴）**：按篇章切分，解决长篇多章节作品的角色串线问题
- **世界书解耦**：拆分「通用设定本 + 各篇章本」，从根本上避免跨篇章 OOC
- **数值面板模式**：为角色追加带 1-10 强度评分的数值面板

## 安装

1. 打开酒馆 → 扩展（Extensions）→ 安装扩展（Install Extension）
2. 粘贴本仓库 URL
3. 安装后，在「扩展」面板的**已安装扩展列表**中找到「角色卡提取工具」，点击展开设置面板

> 也可手动放入 `SillyTavern/data/<user>/extensions/third-party/` 下。

## 使用流程

### 基础流程

1. **小说**：导入或粘贴小说正文（支持 UTF-8 / GB18030 编码识别），可保存记录以便复用。
2. **角色**：手动添加角色名，或点「扫描全书」自动识别；可合并别名。
3. **角色卡**：选择模板与详细程度 → 生成 → 在预览面板核对/编辑 → **确认导入到酒馆**。
4. **世界书**：勾选要生成的内容 → 生成 → 选择「写入酒馆（新建文件）」或「追加到角色绑定」。
5. **人设 / 开场白 / 文风 / 自检**：按需使用。

### 时间线（多章节作品推荐）

> 适用于《刀剑神域》这类分篇章、跨时间线的长篇，避免年龄 / 事件 / 世界观串线。

1. 进入「时间线」页，用两种方式之一划分篇章：
   - **AI 自动划分**：让 AI 识别篇章结构（结果为估算占比，需校对）
   - **按事件名划分**：输入关键事件名（如「死亡游戏开始」，逗号分隔），在正文中**精确检索**其出现位置作为篇章起点
2. **校对并锁定**：调整每个篇章的名称、正文范围、摘要。
3. 回到「角色卡」页，选择时间线模式：
   - **单卡分阶段**：一张卡内按 `## 【SAO篇】` `## 【ALO篇】` 分段
   - **按篇章拆多卡**：每个篇章各生成一张卡

### 世界书解耦（避免 OOC）

> 把世界书拆成两类，游玩时只开启当前篇章本，AI 就不会知道后续剧情。

1. 先在「时间线」页建立篇章。
2. 「世界书」页生成条目后，点「**归类**」→ AI 自动把条目分到：
   - **通用设定本**：跨篇章持续出场的角色基础设定、贯穿全作的全局规则
   - **篇章本**：单篇章专属的 NPC / 反派 / 地点 / 剧情
3. 点「**解耦写入酒馆**」→ 一次写入多本，命名形如：
   ```
   《刀剑神域》·通用设定
   《刀剑神域》·SAO篇
   《刀剑神域》·ALO篇
   ```
4. 游玩时**手动开启当前篇章本**。全局规则类条目会自动设为**常驻（蓝灯）**每一轮注入。

### 数值面板模式

在「角色卡」与「user 人设」页各有一个开关，勾选后会在生成内容末尾追加数值面板提示词：

- AI 先通读原文中的战斗 / 能力表现，给出 **1.0–10.0 强度评分**（保留一位小数）
- 按评分填充等级 / HP 等字段，各角色有区分度（主角 ≠ 路人）
- 字段可自定义；留空则由 AI 依作品类型决定
- user 人设额外给出「与角色的相对强度对比」

## 目录结构

```
card-extractor/
├── manifest.json          # 扩展清单
├── index.js               # 入口
├── settings.html          # 设置面板模板
├── style.css              # 样式
└── src/
    ├── st-bridge.js       # 酒馆 API 适配层（唯一耦合点）
    ├── store.js           # 持久化（extensionSettings + localforage）
    ├── novel.js           # 小说导入与存储
    ├── scan.js            # 角色扫描 / 上下文收集
    ├── timeline.js        # 时间线（篇章划分 / 事件检索）
    ├── prompts.js         # 提示词与模板
    ├── generate.js        # AI 生成封装（generateRaw）
    ├── card-writer.js     # 角色卡写入酒馆
    ├── worldbook.js       # 世界书生成与写入酒馆
    ├── worldbook-split.js # 世界书解耦（通用本 + 篇章本）
    ├── extras.js          # 人设 / 开场白 / 文风 / 自检 / 历史
    ├── util.js            # 通用工具
    ├── ui.js              # 面板主控
    ├── ui-context.js      # UI 共享状态
    ├── ui-novel.js        # 小说 Tab
    ├── ui-timeline.js     # 时间线 Tab
    ├── ui-chars.js        # 角色 Tab
    ├── ui-card.js         # 角色卡 Tab
    └── ui-misc.js         # 其余 Tab
```

## 说明

- 所有 AI 调用走酒馆的 `generateRaw`，由用户在酒馆中配置的接口与模型执行。
- 需在酒馆中处于已连接状态（配置好任意可用的 API）。
- 依赖酒馆共享库：`localforage`（大文本存储）。
- 世界书写入依赖 `loadWorldInfo` / `saveWorldInfo`；角色卡直接创建依赖 `/api/characters/create`，不可用时自动回退为导出 `.json`。
